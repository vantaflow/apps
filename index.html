Installer sur une box Android TV

  1. Sur la box, installez l'application Downloader depuis le Play Store.
  2. Tapez le code indiqué sur la carte (par exemple 5568887 pour Kairo, 2534592 pour Kairo Cast), ou l'adresse du bouton de téléchargement.
  3. Autorisez l'installation quand la box le demande, puis ouvrez l'application une première fois.

Sans Downloader : copiez l'APK sur une clé USB et ouvrez-le avec Kairo Files ou un gestionnaire de fichiers.
