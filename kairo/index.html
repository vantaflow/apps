Écran de veille

Installation

  1. Sur la box, ouvrez Downloader et tapez le code 5568887 : la dernière version se télécharge et s'installe.
  2. Ou copiez l'APK sur une clé USB et ouvrez-le avec un gestionnaire de fichiers (par exemple Kairo Files).
  3. Ouvrez Kairo : l'accueil animé vous guide (écran d'accueil par défaut, recommandations, applications). Tout se retrouve ensuite dans Réglages › Assistant de configuration.

Depuis la version 1.9.0, l'identifiant de Kairo a changé : sauvegardez vos réglages (Réglages › Sauvegarde) avant de passer d'une très ancienne version, puis restaurez-les.
