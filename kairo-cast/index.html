Kairo Cast

L'écran du Mac sur la TV (recopie AirPlay), avec le son, sans limite de durée et sans bords noirs. Fonctionne aussi sans Kairo.

Android TVDownloader 2534592Windows : bientôt
Télécharger l'APK

Fonctionnalités

Recopie AirPlay

Sur le Mac : Centre de contrôle › Recopie de l'écran › « Kairo ».

Sans limite de durée

La recopie dure autant que vous le souhaitez.

Le son aussi

Le son du Mac sort sur la TV.

Netteté réglable

1080p, 1440p (par défaut) ou 4K, selon la box et le réseau.

Trois modes d'affichage

Étirer (par défaut), Remplir ou Ajuster avec les proportions conservées.

Prêt à chaque démarrage

L'application démarre avec la box : la TV est toujours prête à recevoir.

Nom du récepteur au choix

Choisissez le nom qui apparaît sur le Mac.

Petit menu en recopie

La touche OK de la télécommande ouvre un menu pendant la recopie.

Installation

  1. Sur la box, ouvrez Downloader et tapez le code 2534592, puis installez l'application.
  2. Ouvrez-la une fois : elle démarre ensuite toute seule avec la box. Accordez l'affichage par-dessus les autres applications pour que la recopie s'ouvre à tout moment.
  3. Sur le Mac, ouvrez Centre de contrôle › Recopie de l'écran et choisissez « Kairo ».

Une version Windows (appli KairoCast) est prévue : bientôt.
